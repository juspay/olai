# MCP

The plugin owns the protocol server, shared-port HTTP route, tool projection and per-activation session credential table. The listener supplies a composed agent generation and opaque write reservations from the bundle’s static owner declarations. MCP attaches request authority outside RPC input; capability providers enforce it.

`binding.ts` resolves optional directory and write-gate services for each call. A missing vault leaves the protocol available, while domain operations return their ordinary unavailable response. `tickets.ts` narrows a session to its current subtree and combines seat restrictions with static reservations. Released node-shaped credentials remain closed without retaining tombstones. Unloading withdraws the scoped `mcp.ticket-mint` service and carrier; reload allocates a fresh table.

The `/contract` export contains only the optional mint service shape. Tests reach protocol and ticket fixtures through the curated `/testlib` export.
