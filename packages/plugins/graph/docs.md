# Graph

The reference map: every `see`, `doc` attachment, link and `@id` mention the
directory holds, drawn rather than read backwards. `/graph` is the whole
picture; `/graph/<address>` is one record or document's neighbourhood,
narrowed by `?hops=`; a filter prunes the drawing and keeps the centre.

Four rulings stand it on the same floor the rest of the format holds: a
mirror is a view, not a claim; what was put away is at neither end; an
`after` is the ordering table and not a reference; and a vertex is the
record pointed at, no matter how many ways one writer wrote it ([Documents &
references](../format.md)). Over the drawing ceiling the page says how much
it held back rather than rendering a fraction of the map — on the way to
[Trash](trash.md)'s own picture when a centre is archived.

Without this row the reference readings still hold — the pages that derive
from them stay put; only the drawing goes.
