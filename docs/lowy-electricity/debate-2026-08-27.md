## The one call that goes to the human: chat's `@kolu/detect` import

The evidence is unanimous: `@kolu/detect` exports `KOLU_COMMAND`/`KOLU_MCP_ARGS`/`PADI_SOCKET_ENV`; `chat/src/kolu.ts:105-106` spells the literals under a docstring CLAIMING it consumes them (false); the test pins the spelled values so an upstream rename stays green. Also unanimous: chat's three-arm `Detected` and `whyOf`'s five English sentences are JUDGEMENT and cannot cross a wall. The seats crossed mid-sitting on the packaging:

- **Option A — consume in place + one named exception** (pi's final position, fable's closing): widen the existing import to take the three constants, delete the literals, make the docstring true (6 lines). The fence's allowlist is two package homes **plus one named file** (`packages/chat/src/kolu.ts`, `@kolu/detect` only). Blast: a detect-shape change lands in ONE package (chat), which is correct — new failure tag needs a new English sentence only chat can write. Cost: the human's sentence "non-kolu packages don't contain kolu implementation" carries a single, counted, machine-checked asterisk.
- **Option B — a narrow receptacle entry + zero exceptions** (grok's final position): `@olai/kolu-client/detect` re-exports detect's surface; chat imports it; the fence has NO exceptions and the checkmate grep is absolute. Chat's judgement types stay put. Cost: a re-export entry whose only job is a specifier chat already has (the concept-multiplication charge), a `chat → kolu-client` manifest edge for a one-shot probe, and a detect-shape change now lands in TWO packages.

**The moderator's recommendation: Option A** — the blast count favors it and the exception is singular, typed, and written where a reviewer finds it. Option B is the letter of the ruling; A is its cheapest honest spirit. The human picks.

**RULED (the human, 2026-08-27 ~18:17, question tool): OPTION B.** `@olai/kolu-client/detect` re-exports detect's surface; chat imports it and consumes the constants through it (the false docstring dies in the same commit); the fence has ZERO exceptions and the checkmate grep is absolute. Chat's judgement types (`Detected`'s three arms, `whyOf`, `EXPECTED`) stay in chat. The two-package blast on detect-shape changes is the accepted cost.   | grep -v '^packages/kolu-'
```sh
# ⇒ (empty)

# 2. Any olai package named inside kolu-client.
rg -l '^\s*(import|export)\b.*from "@olai/' packages/kolu-client/src
# ⇒ (empty)
```
