# olai

An outliner that lives in files you own. Git records it. A browser edits it. An agent can too.

**[olai.page](https://olai.page)** — what it is, how to run it, and why.

Start here: [olai.page/docs/start](https://olai.page/docs/start/) · All the docs: [olai.page/docs](https://olai.page/docs/)

The docs are Markdown files in [website/docs](website/docs), so they also read on GitHub.

## Status

olai is being developed quickly, and releases will break compatibility. Keep your notes in git.
